### 🌌 AuraPulse — *Voice-first AI wellness companion*
> *Catches burnout before it catches you.*

A native Android app for India's 300 million students and young professionals. A 2-minute daily voice conversation with an AI extracts mood, energy, and stress signals; an on-device burnout-prediction engine spots dangerous trajectories and fires personalised nudges **before** crisis.

- 🎙️ Real-time voice via **Agora ConvoAI + Cartesia STT/TTS + Gemini 2.0 Flash**
- 💬 Typed Chat fallback with keyword-aware scripted mode (so the demo never dies)
- 🧠 Pure-Kotlin burnout engine — 14-day weighted scoring, runs offline
- 🎨 Aura Orb hero visual (custom View, breathing + color-shifting)
- 🔒 Privacy by construction — no account, no cloud sync, audio never persisted
- 🌗 DayNight theming, mirrored light + dark tokens across every surface

`Kotlin` · `XML + ViewBinding` · `Hilt` · `Room` · `MPAndroidChart` · `Retrofit` · `Agora SDK` · `Flask backend on Render`
